# Windows Setup
1. Win+R -> `ms-settings:mousetouchpad`
    1. Enhance Pointer Precision: <b>Disable</b>
    2. Mouse Pointer Speed: <b>5</b>
2. Run `winget configure packages.dsc.yaml`
3. Install the drivers in `drivers.txt`
4. Win+R -> `powercfg.cpl` -> Set High Performance Profile
5. Import `.ptb` file into PowerToys Settings
